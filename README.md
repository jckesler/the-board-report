# The Board Report

A 15 to 20 minute browser game about reporting on a security and privacy program to a board.

You're 90 days into the job as CISO. The audit committee meets Thursday, and you get one page and ten minutes. Choose how to frame the report, which three risks to lead with, which four metrics to show, what changed, what to say about privacy, and what to ask for. Then answer the three directors' questions your choices provoke.

**Play it:** https://jckesler.github.io/the-board-report/

## What it covers

- Framing security as business risk rather than a compliance checklist
- Choosing risks a board can act on, in business terms
- Honest metrics with a trend versus vanity metrics (attacks blocked, training completion, click rates)
- What changed: incidents in the news, AI adoption, privacy developments
- Privacy items worth a board's time: data you keep but don't need, employee monitoring, profiling
- Tying every budget request to a risk
- Answering hard questions without getting defensive

Each play draws one of three invented companies (a health system, a retailer and a software vendor), each with its own directors. You can add a one or two sentence bottom line, and the debrief can be downloaded as a PDF with an optional name and a run code. Pasting the run code into "Check a result" on the start screen rebuilds that exact report, so an instructor can check a submitted PDF in a few seconds. The bottom line is typed text, so it isn't part of the run code.

**Course mode.** Adding `?course=itao511` to the URL shows ITAO 511 module numbers on each card, for students using it as course review.

## Running it

It's a single self-contained HTML file. Open `index.html` in any modern browser, or host it anywhere that serves static files. No build step, no server, no data collected.
